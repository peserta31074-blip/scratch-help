MATERI PRAKTIK

Function dan Procedure

Program dibagi menjadi beberapa bagian supaya mudah dibaca dan diperbaiki.

PROSEDUR

Tampilkan Menu

Menampilkan sapaan “Selamat datang di Toko Digital!” selama 2 detik. Modul ini menjalankan aksi, tanpa menghasilkan nilai baru.

FUNGSI DALAM PRAKTIK INI

Hitung Diskon

Menerima input total_harga, menghitung diskon 10% jika belanja lebih dari Rp100.000, dan menyimpan hasil di Potongan Harga.

Input

answer adalah jawaban dari pertanyaan total belanja. Nilainya dimasukkan ke parameter total_harga.

Proses

Periksa syarat total_harga > 100000. Jika benar, hitung total_harga × 0.1. Jika tidak, hasilnya 0.

Hasil

Variabel Potongan Harga menyimpan jumlah diskon, bukan total yang harus dibayar.

Dalam Scratch 3.0 pada praktik ini, hasil perhitungan disimpan ke variabel. Blok khusus tidak memakai balok return seperti pada contoh fungsi di bahasa lain.

Permasalahan Error

Pilih masalah yang kamu alami. Periksa langkahnya, lalu jalankan program kembali.

12 permasalahan

Program tidak berjalan saat bendera hijau diklik
  1. Pastikan ada blok when green flag clicked pada sprite yang dipakai.
  2. Sambungkan Tampilkan Menu di bawahnya.
  3. Pastikan blok define dan pemanggilnya ada pada sprite yang sama. Blok define saja tidak otomatis berjalan.
when ⚑ clicked
Tampilkan Menu
Sapaan Tampilkan Menu tidak muncul
  1. Buka definisi Tampilkan Menu.
  2. Pasang say [Selamat datang di Toko Digital!] for [2] seconds dari Looks.
  3. Panggil Tampilkan Menu pada program utama. Gunakan say for 2 seconds agar sapaan terbaca sebelum pertanyaan muncul.
Input total_harga tidak ada pada Hitung Diskon
  1. Klik kanan blok Hitung Diskon, pilih Edit.
  2. Klik Add an input (number or text).
  3. Ganti nama input menjadi total_harga, lalu klik OK.
define Hitung Diskon total_harga

Gunakan parameter merah muda dari topi define, bukan membuat variabel oranye dengan nama yang sama.

Potongan Harga tetap 0 padahal belanja lebih dari 100000
  1. Pada program utama, panggil Hitung Diskon (answer) sesudah ask and wait.
  2. Tarik parameter total_harga dari topi define ke sisi kiri operator >.
  3. Isi sisi kanan dengan 100000.
  4. Dalam cabang then, set Potongan Harga ke total_harga × 0.1.
total_harga > 100000

Uji dengan input 150000. Hasil yang diharapkan adalah 15000.

Belanja 100000 menghasilkan diskon 0

Ini sesuai aturan pada LKPD: diskon diberikan jika belanja lebih dari Rp100.000.

  • 90000 → diskon 0
  • 100000 → diskon 0
  • 150000 → diskon 15000

Jadi, jangan mengubah syarat > hanya karena input 100000 menghasilkan 0.

Hasil diskon salah atau terlalu besar
  1. Gunakan operator perkalian × dari Operators, bukan penjumlahan atau pembagian.
  2. Isi perhitungannya dengan total_harga × 0.1. Nilai 0.1 sama dengan 10%.
  3. Masukkan total belanja tanpa Rp dan tanpa titik ribuan. Ketik 150000, bukan 150.000.

Hasil diskon 150000 adalah 15000, bukan 135000. Angka 135000 adalah sisa harga setelah diskon.

Hasil percobaan sebelumnya masih muncul
  1. Gunakan blok if–then–else dari Control.
  2. Di cabang then, set Potongan Harga ke total_harga × 0.1.
  3. Di cabang else, set Potongan Harga ke 0.

Coba 150000 lalu 90000. Hasil harus berubah dari 15000 menjadi 0.

Pertanyaan total belanja atau kotak jawaban tidak muncul
  1. Ambil ask [Berapa total belanja Anda?] and wait dari Sensing.
  2. Letakkan sesudah Tampilkan Menu dan sebelum Hitung Diskon.
  3. Klik bendera hijau, tunggu sapaan 2 detik, lalu ketik angka pada kotak jawaban dan tekan Enter atau tanda centang.

Blok say hanya menampilkan teks. Untuk meminta input, gunakan ask and wait.

Angka jawaban tidak masuk ke Hitung Diskon
  1. Ambil balok oval answer dari Sensing.
  2. Masukkan ke lubang input blok pink Hitung Diskon.
  3. Letakkan pemanggilan tersebut sesudah ask and wait.
Hitung Diskon answer

answer membawa jawaban pengguna. total_harga adalah parameter yang menerima jawaban itu di dalam definisi.

Potongan Harga tidak ada di daftar variabel
  1. Klik Variables → Make a Variable.
  2. Ketik nama Potongan Harga, lalu klik OK.
  3. Gunakan variabel yang sama pada set dan say. Jika ingin melihat nilainya di panggung, centang kotak di samping namanya.

Jangan tertukar: Potongan Harga adalah variabel oranye; total_harga adalah parameter merah muda.

Tampilan hasil hanya berupa teks atau hasil tidak berubah
  1. Ambil blok join dari Operators dan masukkan ke say.
  2. Isi bagian pertama dengan teks Potongan harga Anda: Rp.
  3. Masukkan balok variabel oranye Potongan Harga ke bagian kedua, bukan mengetik nama variabel sebagai teks.
  4. Letakkan say setelah Hitung Diskon (answer).

Untuk input 150000, tampilan yang diharapkan: Potongan harga Anda: Rp. 15000.

Blok ada, tetapi urutan program masih membingungkan

Sambungkan lima bagian berikut dari atas ke bawah, pada sprite yang sama:

  1. when green flag clicked
  2. Tampilkan Menu
  3. ask [Berapa total belanja Anda?] and wait
  4. Hitung Diskon (answer)
  5. say (join [Potongan harga Anda: Rp.] (Potongan Harga))

Blok yang terlepas dari tumpukan utama tidak ikut dijalankan. Define Tampilkan Menu dan define Hitung Diskon tetap menjadi dua tumpukan terpisah.
